# Бренд-байбл — Оплатишка

## Персонаж

**Оплатишка** — дружелюбный гик ~20 лет, который оплатит любую иностранную подписку. Лицо доверия сервиса в чувствительной теме (деньги, обход блокировок). Не клоун, не корпоративный робот — «свой парень, который шарит».

Внешность (канон из ассетов `content_site/`):
- Рыжевато-каштановые вихрастые/кудрявые волосы.
- Синие круглые очки (`glasses-blue #2E3A8C`) — узнаваемая деталь, не убирать.
- Бирюзовое худи (`teal #268B89`) — сигнатурный цвет, всегда на нём.
- Серые джинсы, бирюзовые кеды с белой подошвой.
- Стиль рисовки: комикс/поп-арт — жирные чёрные контуры, halftone-точечная растушёвка, «стикерная» кремовая обводка (`paper #FBFCF7`).

Мимика/позы (из видео): моргает, подмигивает, руки в боки, лёгкая полуулыбка. Базовый вайб — спокойная уверенность + теплота.

## Голос и тон

- Единый голос с Telegram-ботом — берётся из системного промпта `@oplati/agent` (не выдумывать отдельный для веба).
- На «ты», дружелюбно, без канцелярита и без сюсюканья.
- Уверенный в вопросах денег: чётко называет сумму, период, что входит.
- Короткие реплики, разбитые на облака, а не «простыни».
- Юмор — лёгкий, уместный; не превращать оплату в балаган.

## Логотип

Два варианта в `content_site/`:
- На чёрном фоне (для dark-темы / шапки).
- На прозрачном/светлом (для light).

Wordmark «ОПЛАТИШКА» — пухлые округлые bubble-буквы, кремовая заливка (`paper`), комикс-обводка, лёгкая дуга. В UI имя «Оплатишка» в шапке набирать `font-display` (Balsamiq Sans 700) — перекликается с wordmark. (Baloo 2 отклонён — нет кириллицы; Nunito заменён на Balsamiq Sans по фидбеку владельца.)

Правила:
- Не растягивать, не менять цвет заливки на не-бренд.
- Минимальный отступ вокруг = высота буквы «О».
- На пёстром фоне — версия с кремовой обводкой (она и так есть).

## Состояния маскота (для «живого компаньона»)

Таблица «состояние диалога → поза» — ниже (это канонический источник; старая спека `docs/web-design.md` удалена). Ассеты генерируются image-to-image от исходного маскота (см. `higgsfield-recipes.md`) ради консистентности.

| Ключ | Когда | Описание позы |
|---|---|---|
| `idle` | покой/приветствие | базовый луп (есть видео), дышит, иногда подмигивает |
| `wave` | первый экран | машет рукой |
| `thinking` | ожидание ответа агента (стриминга нет — ответ приходит целиком) | смотрит вверх, палец у подбородка |
| `presenting` | подобран каталог | жест рукой в сторону карточек |
| `celebrate` | заказ оплачен | прыжок/триумф, можно с конфетти |
| `handoff` | зову оператора | серьёзнее, жест «передаю» |
| `oops` | ошибка | смущённое «упс», рука к затылку |

`prefers-reduced-motion` → статичная поза без цикла.

## Что НЕ делает бренд

- Не использует стоковую «AI-эстетику» (фиолетовые градиенты, неоновые сетки, glow-частицы).
- Не меняет цвет худи/очков маскота.
- Не пишет русский текст комикс-фонтами без кириллицы.
- Не давит на страх («тебя заблокируют!») — тон помогающий, не пугающий.
- Не злоупотребляет конфетти/звуком — кульминация работает, когда она редкая.
