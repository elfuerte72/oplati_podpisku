# AGENTS.md

**Единственный источник правды для AI-агентов в этом репозитории — [`CLAUDE.md`](./CLAUDE.md).** Прочитай его целиком перед любой работой и следуй ему так, как если бы его содержимое было написано здесь.

Этот файл раньше был самостоятельной копией инструкций и разошёлся с реальностью (аудит 2026-07-11, находка F-20: устаревшие имена ботов, количество таблиц, лимиты сумм, инварианты). Копию больше не поддерживаем — при расхождении прав всегда `CLAUDE.md` + код.

Ключевые правила, которые агенты чаще всего нарушают (полные версии — в `CLAUDE.md`):

- `order_events` — append-only (форсится триггером БД); статусы заказов — только через `transitionOrder()`.
- Деньги — integer в минимальных единицах (копейки / USD-центы), никогда float.
- Zod на всех границах; `any` запрещён.
- Полные PAN/CVC не логируются и не сохраняются никогда.
- Миграции — только forward-only через Drizzle; enum-расширения отдельной миграцией.
- Границы пакетов строгие: `@oplati/agent` не импортирует `@oplati/db` напрямую.
- Webhook-эндпоинты всегда отвечают `200 OK` (кроме `/api/bot` → `401` при неверном secret).
- Не использовать prod Supabase / prod-бота для локальной разработки.
