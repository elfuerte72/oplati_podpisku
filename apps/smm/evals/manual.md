# Проверка руками в Telegram

То, что автотесты не видят: живые кнопки, живой Telegram, живой телефон.
Прогоняется перед выкатом и после каждой правки диалога. Отмечать прямо здесь
датой и исходом — строка на проверку.

Перед началом: бот запущен на тестовом окружении, `SMM_CHANNEL_ID` указывает
на ТЕСТОВЫЙ канал, а не на @ooplatishka.

## Пост канала

- [ ] `/post <ссылка на статью>` — бот отвечает «Собираю» ДО результата, а не после.
- [ ] Приходит вопрос про рубрику; предложенная помечена галочкой и стоит первой.
- [ ] Нажатие рубрики ведёт к вопросу про угол, кнопки прежнего сообщения гаснут.
- [ ] Нажатие угла приводит пост и ОТДЕЛЬНОЕ сообщение с кнопками
      `[Опубликовать] [Правки] [Другой угол] [Снять]`.
- [ ] Сам пост выглядит ровно так, как его увидит читатель: заголовок, тело,
      кнопка продукта, футер со ссылкой на первоисточник.
- [ ] «Опубликовать» → «Выйдет через N с» и кнопка «Отменить».
- [ ] «Отменить» в окне — пост в канал НЕ уходит, кнопки превью возвращаются.
- [ ] «Опубликовать» и ожидание — пост появляется в канале ОДИН раз.
- [ ] Повторное нажатие «Опубликовать» на старом сообщении отвечает «Кнопка устарела».

## Правки

- [ ] «Правки» → «Скажу, что поменять» → текст → пост переписан, кнопки снова есть.
- [ ] «Правки» → «Пришлю свой текст» → мой текст уходит В КАНАЛ ДОСЛОВНО, символ в символ.
- [ ] «Правки» → «Назад» возвращает кнопки превью и НЕ показывает пост заново.
- [ ] «Другой угол» предлагает другие углы, второй раз — отвечает «Кнопка устарела».

## Threads

- [ ] `/threads <ссылка>` доходит до экрана площадки с кнопкой «Открыть в Threads».
- [ ] Кнопка на ANDROID открывает приложение Threads с готовым текстом.
- [ ] Кнопка на iOS открывает приложение Threads с готовым текстом.
- [ ] Картинка приходит отдельным сообщением с фразой «приложи сама».
- [ ] Цепочка из нескольких частей: части приходят блоками, касание копирует блок.
- [ ] «Выложил» отвечает «Отметил как выложенный», в канал НИЧЕГО не уходит.
- [ ] Под опубликованным постом канала есть «Версия для Threads», и она работает.

## Очередь и статистика

- [ ] `/queue` показывает начатые посты с кнопками «Показать» и «Снять».
- [ ] «Показать» из `/queue` приводит пост и кнопки; для поста Threads — экран площадки.
- [ ] «Снять» из `/queue` убирает пост из списка.
- [ ] `/stats` отвечает отчётом, а не тишиной; числа похожи на правду.
- [ ] `/ideas` показывает темы с кнопками «Написать», «Пропустить», «Не по теме».
- [ ] «Написать» из `/ideas` сразу начинает пост, вопрос про ссылку не задаётся.
- [ ] `/settings digest 10` включает дайджест, `/settings` показывает его состояние.

## Чужие и мелочи

- [ ] Сообщение НЕ от владельца бот игнорирует молча (проверить со второго аккаунта).
- [ ] `/QUEUE` заглавными работает так же, как строчными.
- [ ] Незнакомая команда отвечает меню, а не тишиной.
- [ ] Перезапуск бота в окне отмены: пост в канал не уходит, приходит сообщение
      о возврате в превью.
