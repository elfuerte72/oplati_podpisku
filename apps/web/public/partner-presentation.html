Суть

Ты и твои друзья — один уровень

Ты приглашаешь людей по личной ссылке. С каждой их оплаты тебе капает процент. Никаких сетей, уровней и сложных схем — только те, кого ты привёл лично.

Ставка

Один процент — с каждой оплаты

Базовая ставка — 4% с любой оплаты приглашённого тобой друга. Со статусом она растёт — дальше.

Бонусы

Сверх процента — 4 усилителя

Достижение статуса

Разовый бонус при подъёме: +$50 (Партнёр), +$150 (Топ-партнёр).

Спринт новых

10+ новых активных рефералов за месяц → +$30.

Серия

3 месяца подряд с выполненным планом → +$25 / $75 / $200 (по статусу).

Буст оборота

Оборот сети ≥ 150% плана → +1% к ставке на следующий месяц.

Статусы и бонусы пересчитываются автоматически по итогам каждого месяца.
