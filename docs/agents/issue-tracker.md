# Трекер задач: локальный markdown

Тикеты и спеки скиллов живут файлами в `.scratch/` — не в GitHub Issues.

**Почему не GitHub Issues:** репозиторий публичный, а тикеты содержат рабочие детали
контура оплаты (суммы, имена env, куски логов). Публиковать их наружу ради удобства
трекера смысла нет, а `gitleaks` в CI ловит только известные форматы секретов.

⚠️ **`.scratch/` в `.gitignore`** — по той же причине: содержимое не попадает в публичную
историю. Плата за это — тикеты живут только на текущей машине и не видны в PR. Если
понадобится делиться ими, убери строку из `.gitignore` и перечитай абзац выше.

## Границы: что где живёт

| Где | Что | Кто ведёт |
|---|---|---|
| `docs/BACKLOG.md` | **единственный** список «на потом»: отложенное, открытые находки аудитов, идеи | человек, вручную |
| `.scratch/<feature>/` | тикеты работы, которая идёт **прямо сейчас**: спека, разбивка, карта wayfinder | скиллы |
| `docs/CHANGELOG.md` | что уже сделано | человек, обязательно |

Задача, уехавшая «на потом», переносится из `.scratch/` в `docs/BACKLOG.md` — и
удаляется из `.scratch/`. Двух списков отложенного быть не должно. Закрытый трек может
остаться в `.scratch/` как локальный архив (каталог не в git, ссылаться на него из `docs/`
нельзя — история решений живёт в `CHANGELOG.md`).

## Соглашения

- Одна фича — одна директория: `.scratch/<feature-slug>/`
- Спека — `.scratch/<feature-slug>/spec.md`
- Тикеты реализации — по файлу на тикет: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`,
  нумерация с `01`; объединённого файла со всеми тикетами не бывает
- Состояние триажа — строкой `Status:` вверху файла тикета (строки ролей — в
  `triage-labels.md`)
- Обсуждение дописывается в конец файла под заголовком `## Comments`

## Когда скилл говорит «опубликовать в трекер»

Создать новый файл в `.scratch/<feature-slug>/`, создав директорию при необходимости.

## Когда скилл говорит «взять тикет»

Прочитать файл по указанному пути. Обычно пользователь передаёт путь или номер тикета сам.

## Операции wayfinder

(Раскладка на будущее — `/wayfinder` в этом репозитории пока не запускался, файлов `map.md` нет.)

Используются `/wayfinder`. **Карта** — файл, к которому привязаны **дочерние** файлы-тикеты.

- **Карта**: `.scratch/<effort>/map.md` — тело Notes / Decisions-so-far / Fog.
- **Дочерний тикет**: `.scratch/<effort>/issues/NN-<slug>.md`, нумерация с `01`, вопрос — в
  теле. Строка `Type:` фиксирует тип тикета (`research`/`prototype`/`grilling`/`task`),
  строка `Status:` — `claimed`/`resolved`.
- **Блокировки**: строка `Blocked by: NN, NN` вверху файла. Тикет разблокирован, когда все
  перечисленные файлы в состоянии `resolved`.
- **Фронтир**: просмотреть `.scratch/<effort>/issues/` на предмет файлов открытых,
  разблокированных и незанятых; побеждает первый по номеру.
- **Занять**: выставить `Status: claimed` и сохранить ДО начала работы.
- **Решить**: дописать ответ под заголовком `## Answer`, выставить `Status: resolved`, затем
  дописать указатель (суть + ссылку) в Decisions-so-far карты `map.md`.
