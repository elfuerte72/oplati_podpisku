# Метки триажа

Скиллы говорят пятью каноническими ролями триажа. Здесь роль сопоставлена со строкой,
которая реально пишется в тикет.

Трекер локальный (`.scratch/`), меток как сущности у него нет — роль записывается строкой
`Status:` вверху файла тикета.

| Роль в скиллах | Строка у нас | Значение |
|---|---|---|
| `needs-triage` | `needs-triage` | Нужно оценить задачу |
| `needs-info` | `needs-info` | Ждём уточнений от постановщика |
| `ready-for-agent` | `ready-for-agent` | Полностью описана, можно отдать агенту без присмотра |
| `ready-for-human` | `ready-for-human` | Требует человека |
| `wontfix` | `wontfix` | Делать не будем |

Пример строки в теле тикета:

```markdown
Status: ready-for-agent
```

⚠️ **`ready-for-agent` для денежных путей ставит только владелец.** Изменения в оплате,
вебхуках, выпуске карт, реферальных начислениях и миграциях БД не уходят агенту без
присмотра — цена ошибки терминальна (см. инварианты в `CLAUDE.md`). Для них — `ready-for-human`.
