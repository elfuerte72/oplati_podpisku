## Что учесть при сборке

- **Судья и автор — разные модели.** С 2026-09-14 DeepSeek обслуживает `deepseek-v4-pro` и
  `deepseek-v4-flash` одной V4.1-Flash (актуальный id `deepseek-flash`); редактор на той же
  модели, что автор, хвалит его же обороты.
- **Публикация — только по кнопке владельца**, и решение читается из журнала, а не со слов
  модели (fail-closed). Правило Гилфойла, добытое самопубликацией 2026-09-08.
- **Threads — Web Intent**, автопостинг только в Telegram (решение владельца 2026-09-15);
  API Threads требует ревью Meta и 60-дневный токен.
- **Красные линии текстов не менялись:** страна выпуска карты, провайдеры и эмитент,
  реквизиты, сбои и инциденты Оплатишки, гарантии возврата, цены в рублях и курс по памяти,
  выдуманные цифры, отзывы и клиенты. Что можно оплатить — только из `/api/catalog`.
