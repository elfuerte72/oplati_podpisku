# Threads для SMM-агента: ресерч и что из него зашито в код

Ресерч проведён 2026-09-15 перед тем, как научить Гилфойла писать посты для Threads
(`/postthreads`). Устройство агента — [`smm-agent.md`](smm-agent.md); здесь факты о площадке,
на которых стоят линт `lint_threads`, советник `advise --platform threads`, скилл
`threads-copy` и передача поста владельцу через Web Intent. Каждый факт помечен, откуда он:
[ОФИЦ] — документация и заявления Meta, [ПРАКТ] — данные практиков, [СЛУХ] — не подтверждено.

**Что из ресерча стало кодом (15.09.2026):** потолок 480 знаков на часть с эмодзи за четыре;
запрет разметки, буллетов и «математического жирного»; крючок первой строкой до 120 знаков;
ссылка только в последнем ответе и одна на цепочку; тема через параметр `tag`, не решёткой;
до пяти частей без нумерации; стоп-фразы engagement bait и рекламы по 72-ФЗ; отказ на
предложении дословно из поста канала; Web Intent на `threads.com` без параметра `url`
(теряется на Android). **Что осознанно не сделано:** публикация через Threads API (владелец:
автопостинг только в Telegram), Snippet на 10 000 знаков (через intent недоступен),
автоматическая нарезка длинного текста (агент режет сам, линт проверяет).

---

Дата проверки: 2026-09-15. Цель — научить агента писать отдельные посты для Threads, которые человек публикует руками через Web Intent (`threads.net/intent/post?text=…`), без автопостинга.

**Маркировка фактов:**
- **[ОФИЦ]** — подтверждено Meta (документация для разработчиков, Newsroom, Transparency Center, Help Center, официальные аккаунты @threads / @mosseri / @threadsapi.changelog).
- **[ПРАКТ]** — наблюдения и данные практиков (Buffer, Hootsuite, Metricool, Postory, вендорские исследования, русскоязычные кейсы). Данные вендоров — направление, не закон.
- **[СЛУХ]** — не подтверждено ни Meta, ни воспроизводимыми данными.

Все ссылки — в разделе 11.

---

## 0. Главное за минуту

1. Один пост — **500 знаков** [ОФИЦ]; «длинный текст» (Snippet, бывший Text attachment) — **10 000 знаков** [ОФИЦ], но его через Web Intent не передать.
2. Разметки в основном посте **нет** (ни жирного, ни курсива, ни заголовков, ни таблиц) [ОФИЦ по факту отсутствия в композере и API]. Форматирование есть только внутри Snippet.
3. **Один topic tag на пост** [ОФИЦ], 1–50 символов, без точек и амперсандов.
4. Ссылки **не понижаются в ранжировании** (Mosseri, 21.11.2024) [ОФИЦ], но посты со ссылками собирают меньше реакций (Buffer 2026: 2,34 % против 2,79 % у текста) [ПРАКТ]; русскоязычный кейс: ссылка в тексте — в 7 раз меньше просмотров [ПРАКТ, один аккаунт]. Практическое правило: ссылку — в первый реплай, не в пост.
5. Два официальных ограничителя охвата [ОФИЦ, @threads 21.10.2024]: нарушение Recommendation Guidelines (включая кликбейт и engagement bait) и **неоригинальный контент**. Копипаста из Telegram — второй пункт.
6. Реплаи — половина всех просмотров в Threads [ОФИЦ]; «отвечайте больше, чем постите» (Mosseri) [ОФИЦ]; ответы автора под своим постом дают +42 % вовлечённости (Buffer, 128 тыс. постов) [ПРАКТ].
7. Web Intent [ОФИЦ]: параметры `text`, `url`, `tag`, `reply_control`, `reply_post_shortcode`, `quote_post_shortcode`; всё percent-encoded; на телефоне открывает приложение, на десктопе — новое окно. Медиа передать нельзя. Известный баг: на Android параметр `url` теряется при переходе в приложение [ПРАКТ].
8. Русскоязычный Threads — это в первую очередь **не Россия**: Казахстан 1,85 млн, Украина 1,75 млн, Узбекистан 834 тыс., Кыргызстан 538 тыс., Беларусь 533 тыс. (DataReportal, конец 2025) [ПРАКТ]; по России Mediascope данных не публикует, агентство «Родная речь» оценивает дневную аудиторию в ~300 тыс. (рост +88 % за январь–май 2026) [ПРАКТ].
9. Русскоязычные пользователи Threads обсуждают ИИ **практически**: подписки, лимиты, «как заплатить», VPN (gro.now, 4 899 постов, июль 2026) [ПРАКТ] — это ровно боль Оплатишки.
10. Юридически для РФ: Meta — экстремистская организация (с 21.03.2022), с 01.09.2025 действует запрет рекламы на её ресурсах (72-ФЗ, ч. 10.7 ст. 5 ФЗ «О рекламе»). Информирование о собственных услугах на своей странице ФАС рекламой не считает; промокоды, скидки, «только сегодня» — считает. В Telegram-канале упоминать Threads с пометкой об экстремизме Meta, без логотипа.

### 1.2. Ссылки

- Кликабельны. Превью-карточка — **одна на пост**: через API это `link_attachment`, а без него «первая ссылка в текстовом посте становится link attachment и показывается как превью» [ОФИЦ, Threads API › Posts]. В приложении с сентября 2024 есть отдельная кнопка прикрепления ссылки [ОФИЦ, @anujs3 12.09.2024].
- **Не больше 5 ссылок на пост** (inline + attachment); с 22.12.2025 API отдаёт ошибку `THREADS_API__LINK_LIMIT_EXCEEDED` [ОФИЦ, @threadsapi.changelog 08.12.2025].
- Превью строится по `og:image` сайта [ПРАКТ]; у bot-ссылок `telegram.me/...` превью будет карточкой Telegram.
- До 5 ссылок в био профиля [ОФИЦ по анонсу 2025].

### 1.3. Topic tags

- **Один тег на пост** [ОФИЦ]: Help Center «You can include up to 1 topic per post»; @threads, декабрь 2023: «You can only tag one topic per post… This makes it easier for others who care about that topic to find and read your post».
- Добавляется кнопкой «Add a topic» или через `#` в тексте — символ `#` исчезает, фраза становится синей; можно несколько слов с пробелами. Если написать несколько `#`, тегом станет **первый**, остальные останутся обычным текстом [ПРАКТ, louisem/postory].
- Правила API [ОФИЦ]: 1–50 символов; запрещены точка и амперсанд; для тега внутри текста — ещё пробелы, табы, переносы, `@ ! ? , ; :`.
- Любое слово поста ищется поиском и без тега [ОФИЦ, @threads].

### 1.5. Лимиты частоты

- **API** [ОФИЦ]: 250 опубликованных постов / 24 ч (скользящее окно), 1 000 реплаев / 24 ч, 100 удалений / 24 ч.
- **Приложение**: Meta лимиты не публикует. Практики называют «~20 постов в день», новые аккаунты — «1 пост в 2 часа» [СЛУХ, BlackHatWorld]. Русскоязычный кейс: при 10–13 постах в день с автоматизацией алгоритм «распознал автоматизацию», охват упал с ~150 до 20 просмотров; после снижения до 5–7 в день восстановился [ПРАКТ, один аккаунт, mysummit.school 06.12.2025]. Вендорское исследование: 6+ постов в день дают −67 % охвата против 2–3 [ПРАКТ, Teract Q1 2026].

## 2. Алгоритм и распространение

### 2.1. Что официально известно о ранжировании

**System card «Instagram Threads Feed AI system»** (Transparency Center, обновлено 07.03.2025) [ОФИЦ]. Лента смешивает подписки и рекомендации; есть отдельная «Following» — хронологическая. Модели предсказывают: вероятность лайка; вероятность пролистнуть; вероятность кликнуть на пост; кликнуть в профиль автора; кликнуть в профиль и открыть ещё один пост; **создать реплай**; кликнуть на пост и лайкнуть; время на странице поста; время просмотра поста. Входные сигналы — история взаимодействий читателя, «descendant engagement» (активность в ветке реплаев), время, платформа. **Про ссылки, оригинальность и «качество реплаев» в карточке ничего нет.**

**Что Meta понижает (Transparency Center «Types of content we demote», обновлено 02.07.2025)** [ОФИЦ]: clickbait links, **engagement bait**, fact-checked misinformation, контент на грани нарушения стандартов. Instagram Recommendation Guidelines (на них ссылается @threads) выделяют «content that users broadly tell us they dislike, including clickbait, engagement bait, or which promotes a contest or giveaway» — «Comment YES if you agree» назван примером.

**Rage bait**: в октябре 2024 Mosseri признал проблему и обещал её решать [ОФИЦ по Social Media Today 07.10.2024]. Фраза «not all comments or replies are good» широко приписывается Mosseri в гайдах 2026 года, дословного первоисточника я не нашёл [ПРАКТ, цитата не верифицирована].

### 2.3. Что это значит для отдельных вопросов из ТЗ

- **Ссылки**: не штраф [ОФИЦ], но пост со ссылкой — самый слабый формат по реакциям [ПРАКТ, Buffer 2026]. Официального «ставьте ссылку в реплай» нет; это консенсус практиков, подтверждённый русскоязычным кейсом.
- **Rate-limit**: для ручного постинга не актуален; ориентир — 1–3 поста в день, не больше 5.
- **Хештеги**: только один topic tag; «стена тегов» невозможна технически.
- **Цитирование и репосты**: официальных данных нет. Практики: quote post (с комментарием) лучше голого репоста [СЛУХ]. Репост чужого без добавления — риск «unoriginal content» [ОФИЦ по формулировке @threads].
- **Кросспост из Instagram**: есть авто-шеринг (только одиночные фото, подпись режется до 500) [ОФИЦ по анонсам]; Meta советует делать контент под Threads [ОФИЦ]; вендор: наличие 10K+ в Instagram ускоряет рост в 4 раза [ПРАКТ].
- **Первые часы**: Meta про «окно» не говорит. Практики (Hootsuite, Teract) — «первые 2 часа»; system card оперирует «descendant engagement», то есть ветка реплаев важна безотносительно времени [ОФИЦ].
- **Reply-baiting / engagement bait**: «Comment YES if you agree», «like if…», конкурсы — прямо названы нежелательными [ОФИЦ]. Обычный вопрос по теме — не bait.

## 3. Формат текста, который работает

Сводка практик (везде [ПРАКТ], если не указано иное):

1. **Длина.** 100–300 знаков для одиночного поста; полные 500 — только когда есть ради чего. Официально Meta длину не регламентирует. Данные: Hootsuite <200; Teract 100–200 + картинка; mysummit 100–200; Buffer — «посты до 500 знаков собирают больше, чем длинные с attachment».
2. **Хук — первая строка.** Лента режет пост после первых строк («…more»), поэтому первое предложение должно работать само. Заголовков нет — хук и есть заголовок, но написанный как реплика, не как тайтл.
3. **Вопрос против утверждения.** Официально: «posts that drive conversations are more likely to get recommended». Вопрос в конце — ×2,3 реплаев (вендор). Но вопрос должен быть настоящим («кто уже пробовал — стало лучше?»), а не «согласны?».
4. **Hot take.** Работает, если в нём есть куда ответить; «утверждение без приглашения» проигрывает (Postory). Негатив и споры ради спора — −58 % (вендор) и попадают под rage bait.
5. **Списки.** Только строками с переносами; без буллет-символов Telegram-стиля («•», «▪️»); лучше тире или цифры; ≤ 5 пунктов, каждый — одна строка.
6. **Заголовки.** Нет. Пост начинается сразу с сути.
7. **Тред = пост + свои реплаи.** Официальный механизм — «Add to thread» или последовательные ответы себе; лента показывает 1-й и 2-й пост + счётчик. Нумерация «1/…» не нужна; «1/14» отпугивает; 3–5 частей — норма. Каждая часть должна читаться отдельно (в рекомендации может попасть любая).
8. **Эмодзи.** Умеренно: 0–3 на пост; не как маркеры списка. Вендор: 2–3 → +18 %, 6+ → −22 %.
9. **CTA.** Приглашение к разговору, а не к действию с продуктом. «Сохрани», «поделись» — нейтрально; «лайк если», «напиши да» — bait.
10. **Ссылка.** В первом реплае («ссылка в комментариях» — устоявшаяся практика Threads), либо в био. В посте — только если сама ссылка и есть новость.
11. **Картинки и скриншоты.** Официально: медиа с текстом получает больше просмотров. Скриншот интерфейса модели, таблица цен в виде картинки — рабочий формат. Через intent картинку не передать, человек прикладывает сам, поэтому текст обязан быть самодостаточным.
12. **Оригинальность.** Пересказ чужой новости своими словами с собственным выводом — оригинальный контент; дословный перевод заголовка — нет.
13. **Тон.** Разговорный, короткие предложения, от первого лица, допускается ирония. Официальный гайд Meta: «funny content receives a higher number of views».

## 4. Русскоязычная аудитория Threads

### 4.1. Статус и размер

- **Доступность.** Threads принадлежит Meta и работает на инфраструктуре Instagram, поэтому в России недоступен без VPN с момента запуска 06.07.2023; Роскомнадзор формально его не блокировал и заявлял, что сеть «сможет работать при соблюдении законодательства» (РИА, 06.07.2023) [ОФИЦ по заявлению РКН]. Реклама в Threads из РФ невозможна (нельзя платить Meta).
- **Глобально**: 500 млн MAU (Meta, 16.06.2026) [ОФИЦ]; DAU ~143 млн (январь 2026, оценка) [ПРАКТ].
- **Россия**: Mediascope Threads в открытых рейтингах не публикует — «отдельной российской статистики нет» (natiw.ru, 18.08.2026). Оценка «Родной речи» (Коммерсантъ, 02.07.2026): **дневная аудитория 300,7 тыс., +88,3 % за январь–май 2026** — на фоне Instagram 7,4 млн и Facebook 114 тыс. [ПРАКТ]. Threads — самая быстрорастущая из зарубежных сетей в РФ, но в абсолюте маленькая.
- **Русскоязычные страны (DataReportal, конец 2025, через рекламный кабинет Meta)** [ПРАКТ]: **Казахстан 1,85 млн** (59 % женщины; ~9 % населения), Украина 1,75 млн, Узбекистан 834 тыс., Кыргызстан 538 тыс., Беларусь 533 тыс. Вывод для Оплатишки: пишем для русскоязычного человека **вне РФ или с VPN**, у которого уже есть проблема оплаты иностранных сервисов. Это сужает аудиторию, но точно попадает в боль.

### 4.2. Что заходит

- Формат «текст как в ЖЖ/Твиттере»: без монтажа и фотошопа, мысль вслух, наблюдение, «что бесит» (vc.ru 01.2026).

- Новости и эмоции работают лучше обучающего контента; темы «рынок труда и ИИ», мировые AI-новости (mysummit, RU).
- Мемы копируются бесконечно — оригинальность заметна на этом фоне (sdelaem.agency).
- Контент живёт 6–12 часов, реплаи под чужими постами — рабочий канал (allweb.ru, vc.ru).
- **Про ИИ конкретно** (gro.now через the-tech.kz, 30.07.2026: 7 785 постов, 4 899 релевантных, июль 2023–июль 2026): ChatGPT 28 % упоминаний (маркетинг, презентации), Claude 18 % (код, автоматизация), Gemini 16 % (переводы), DeepSeek 11 %, Perplexity (поиск); тон нейтральный (88 %); **обсуждают подписки, лимиты, оплату, VPN; главный барьер — «как мне за него заплатить?»**; люди собирают «портфель инструментов под задачи», а не ищут «лучшую нейросеть вообще».

### 4.5. Юридическая сторона для РФ

**Статус Meta.** Тверской суд Москвы 21.03.2022 признал Meta Platforms Inc. экстремистской организацией и запретил деятельность Facebook и Instagram в РФ (WhatsApp исключён). Threads создан позже, но принадлежит Meta и на инфраструктуре Instagram — фактически заблокирован с запуска [ОФИЦ по судебному решению и заявлениям РКН].

**Пометка при упоминании.** Ч. 2 ст. 13.15 КоАП: упоминание организации из перечня экстремистских без указания на запрет её деятельности — штраф гражданам до 2 500 ₽, должностным лицам до 5 000 ₽, юрлицам до 50 000 ₽. Требование распространяется на любых распространителей, не только СМИ; закон не задаёт, сколько раз и где ставить пометку — Центр защиты прав СМИ советует в скобках после первого упоминания или сноской (ГАРАНТ; vc.ru 22.03.2022). Устоявшаяся форма в русскоязычных медиа: **«Threads*» + сноска «*принадлежит Meta Platforms Inc., признанной экстремистской организацией, деятельность которой запрещена в РФ»**. Примеры реальных формулировок: vc.ru — «Threads*»; kokoc — «Meta (признана экстремистской организацией и запрещена в России, владеет Facebook)»; trafficcardinal — «Meta признана экстремистской и запрещена на территории РФ».

**Логотип.** Ст. 20.3 КоАП — демонстрация символики экстремистской организации: гражданам до 15 суток ареста, юрлицам до 50 000 ₽. Практика: не показывать логотипы Meta/Instagram/Threads в постах и на сайте (roskomsvoboda, vc.ru 2022).

**Реклама с 01.09.2025.** 72-ФЗ от 07.04.2025 добавил ч. 10.7 в ст. 5 ФЗ «О рекламе»: запрещено распространение рекламы на информационных ресурсах организаций, чья деятельность запрещена по основаниям экстремизма/терроризма [ОФИЦ по тексту закона]. Threads по имени в разъяснениях ФАС не фигурирует, но как ресурс Meta подпадает по букве закона. Штрафы по ст. 14.3 КоАП: граждане 2–2,5 тыс. ₽, ИП/должностные 4–20 тыс. ₽, юрлица 100–500 тыс. ₽. ФАС: информация о собственных товарах/услугах на своей странице (ассортимент, условия, цены, правила) — **не реклама**, если она информирует; **промокоды, скидки, акции, «только сегодня», яркая позитивная оценка с призывом купить — реклама** (разъяснения ФАС 2025; setters.media 01.09.2025; e-kontur). Старые посты до 01.09.2025 не нарушение, пока их не распространяют повторно (закреп, репост, ссылка на них).

**Оплата Meta** (реклама, бусты) — риск квалификации как финансирования экстремизма (ст. 282.3 УК) — не делать никогда.

Практические правила для канала-витрины из РФ:
1. В Threads — только информирование и экспертный контент; **никаких промокодов, скидок, «успей», «только до пятницы»** (в отличие от Telegram).
2. Описание Оплатишки — нейтральное: «сервис, который оплачивает иностранные подписки за рубли» без «лучший», «выгоднее всех».
3. В Telegram-канале при упоминании Threads — пометка об экстремизме Meta, без логотипа. Внутри самого Threads пометка не нужна (юрисдикция ресурса), но и вреда от неё нет.
4. Юридическую консультацию по конкретным формулировкам — получить до старта: судебной практики именно по Threads я не нашёл.

## 5. Адаптация из Telegram в Threads

**Не переносится и должно быть вырезано линтом:**

| Элемент TG-поста | Что с ним в Threads |
|---|---|
| Заголовок | Нет заголовков. Хук — первое предложение поста |
| Жирный/курсив/подчёркивание/спойлер | Нет. Unicode-подмены — не использовать (доступность, поиск, «как у ботов») |
| Таблица | Нет. Либо 2–4 строки «A — B», либо картинка со скриншотом таблицы (прикладывает человек) |
| Список 5–10 пунктов | Только строки; ≤ 5 пунктов; иначе — разложить по реплаям |
| Кнопка / inline-клавиатура | Нет. Ссылка в реплае словами |
| Футер «Источник: …» | Нет. Либо «по данным X» внутри фразы, либо ссылка на источник в реплае |
| Несколько ссылок | Одна на пост, в реплае; максимум 5 технически |
| Обложка/картинка | Через intent не передаётся. Агент отдаёт человеку файл + alt-текст отдельно |
| Хештеги пачкой | Один topic tag через параметр `tag` |
| Эмодзи как маркеры пунктов | Убрать, оставить 0–3 эмодзи на пост |
| «Экспертный» тон, канцелярит | Разговорный, «ты», короткие фразы |

**Как резать длинный пост в цепочку:**

1. Одна идея на цепочку. Первый пост — хук + главный вывод (100–300 знаков), обязан жить сам по себе.
2. Реплаи 2–4 — по одному тезису/примеру каждый, ≤ 400 знаков, тоже самодостаточные.
3. Последний реплай — ссылка (бот/сайт) с одной фразой «зачем нажимать».
4. Всего ≤ 5 частей; без «1/5».
5. Если материал требует больше — это два разных поста в разные дни, а не тред на 8 частей.

**Механика ручной публикации цепочки через intent.** Параметр `reply_post_shortcode` требует shortcode уже опубликованного поста, которого до публикации нет. Поэтому агент выдаёт: (а) intent-URL для первого поста, (б) тексты реплаев отдельными блоками для копирования (человек публикует их через «Add to thread» или ответом себе), (в) на всякий случай intent-URL для каждого реплая без `reply_post_shortcode` — если человек предпочтёт вставить shortcode руками.

**Картинка.** Обложка из TG-поста может не подходить: Threads показывает картинки крупно, рекомендованные 4:5 (1080×1350) или 1:1; текст на обложке должен читаться на телефоне. Агент отдаёт alt-текст (≤ 1 000 знаков, с фактами, а не «картинка»).

**Ссылка на бота/сайт.** Не в каждый пост. Ориентир: ссылка в реплае у 1 из 3–5 постов, плюс постоянная ссылка в био (до 5 ссылок). Пост, весь смысл которого — «переходи в бота», в Threads не соберёт ни реплаев, ни рекомендаций (mysummit: 338 тыс. просмотров → 1 регистрация при ссылках в постах).

## 6. Threads Web Intent — контракт

**Документация:** developers.facebook.com/docs/threads/threads-web-intents (проверено 15.09.2026). Домен в документации — `https://www.threads.com/intent/post`; `threads.net` редиректит на `threads.com` (домен сменён в 2025). Endpoint анонсирован инженером Threads @0xjessel в январе 2024: «the route is `/intent/post?text={...}`, with the text param being the URL-encoded string you want to prefill».

**`GET https://www.threads.com/intent/post`** [ОФИЦ]:

| Параметр | Обязателен | Описание (дословно) | Ограничения |
|---|---|---|---|
| `text` | нет | «The text that the post dialog should be prefilled with» | лимит не задокументирован; композер не даст отправить >500 знаков |
| `url` | нет | «The URL for an optional link attachment» | одна ссылка; на Android теряется (см. баги) |
| `tag` | нет | prefill topic tag | «Newlines, tabs, periods (.), and ampersands (&) are not allowed», ≤ 50 символов |
| `reply_control` | нет | кто может отвечать | `everyone`, `accounts_you_follow`, `mentioned_only`, `followers_only` |
| `reply_post_shortcode` | нет | «The shortcode of the parent post that you are replying to» | shortcode — часть URL поста `threads.com/@user/post/<shortcode>` |
| `quote_post_shortcode` | нет | «The shortcode of the post that is being quoted» | — |

**`GET https://www.threads.com/intent/follow?username=…`** — подписка [ОФИЦ].

**Кодирование** [ОФИЦ]: «All parameter values should be encoded using percent-encoding». Переносы строк — `%0A` (работает, подтверждено генераторами share-ссылок [ПРАКТ]). Медиа, опросы, спойлеры, Snippet — параметров **нет**.

**Поведение** [ОФИЦ]: «On mobile (iOS and Android), web intents will open the Threads app whenever it is installed»; на десктопе «a new window opens»; не залогиненный «will have the opportunity to sign in or create a Threads account».

**Длина URL.** Meta лимит не публикует. Кириллица в percent-encoding занимает 6 символов на букву (`%D0%9F`), поэтому пост в 500 кириллических знаков даёт URL ≈ 3 000–3 300 символов. Современные браузеры это переваривают (Chrome — до 2 МБ, Safari — десятки КБ), но «классический» безопасный порог 2 048 символов превышен: QR-коды, некоторые прокси и мессенджеры могут обрезать. Правило: intent-URL передавать человеку как кликабельную ссылку в интерфейсе агента (не через QR и не через СМС), и проверить одним живым тестом на iOS и Android.

**Известные баги / грабли:**
- На Android при переходе из браузера в приложение параметр `url` теряется, на iOS и вебе — работает (обсуждение в Threads-комьюнити разработчиков) [ПРАКТ]. Обход: ссылку класть внутрь `text`, а не в `url`; но тогда она попадает в основной пост — против нашего правила «ссылка в реплае». Итог: `url` не использовать, ссылку публиковать реплаем руками.
- Текст длиннее 500 знаков просто не отправится — композер покажет красный счётчик; человек будет резать руками. Линт обязан не выпускать >500 (с запасом на эмодзи).
- `#` внутри `text` превращает первое слово после него в topic tag [ПРАКТ]; если одновременно передан `tag`, поведение не документировано — использовать что-то одно (`tag`).
- Черновик в композере может потерять переносы, если `%0A` пришли как `\n` без кодирования — кодировать всегда `encodeURIComponent`.

## 7. Threads API (справочно: цена «публикации одной кнопкой»)

Всё [ОФИЦ] по developers.facebook.com/docs/threads (проверено 15.09.2026).

- **Приложение Meta** с use case «Threads»; у приложения два App ID — использовать Threads App ID и его секрет.
- **Скоупы**: `threads_basic` (обязателен везде), `threads_content_publish` (публикация), `threads_manage_replies` / `threads_read_replies` (реплаи), `threads_delete`, `threads_location_tagging`, `threads_manage_insights` (аналитика).
- **App Review**: «In order for app users without a role on your app to be able to grant your app these permissions, each permission must first be approved through the App Review process, and your app must be published». Обратная сторона: **для своего собственного аккаунта App Review не нужен** — аккаунт добавляется как Threads Tester в App Dashboard (приглашение принимается в настройках Threads), и токен для него выдаётся до всякого ревью. Это и есть дешёвый путь «одна кнопка для одного аккаунта».
- **Токены**: короткоживущий 1 час → обмен на долгоживущий **60 дней**; refresh через `GET /refresh_access_token`, когда токену ≥ 24 ч и он ещё не истёк. Нужен крон на обновление раз в месяц, иначе через 60 дней публикация молча встанет.
- **Публикация**: два шага — создать media container (`POST /{id}/threads`) → опубликовать (`POST /{id}/threads_publish`); рекомендовано ждать ~30 с между ними. **Медиа должны лежать по публичному URL** («The media must be hosted on a publicly accessible server at the time of the attempt») — то есть под обложки нужен свой публичный хостинг (у Оплатишки есть R2/сайт).
- **Лимиты**: 250 постов / 24 ч, 1 000 реплаев / 24 ч, 100 удалений / 24 ч; карусель = 1 пост; ≤ 5 ссылок; 500 знаков (эмодзи считаются байтами UTF-8).
- **Параметры контента**: `text`, `media_type` (TEXT/IMAGE/VIDEO/CAROUSEL), `link_attachment`, `topic_tag`, `reply_to_id`, `reply_control`, `alt_text`, `quote_post_id`, `poll_attachment`, `auto_publish_text` (публикация текстового поста в один шаг, без отдельного container).
- **Изменения**: канал `@threadsapi.changelog` в Threads (лимит ссылок анонсирован там за 2 недели).

**Оценка цены**: 1–2 дня разработки (OAuth-флоу, крон refresh, публичный хостинг картинок, очередь «пост → реплаи»), ноль денег Meta (API бесплатный). Юридически из РФ — тот же режим, что и ручной постинг (оплаты Meta нет). Главный операционный риск — молчаливое протухание токена.

## 8. Рекомендованный формат поста для Threads для этого канала

Общие рамки: «ты», разговорно, одна идея, хук первой строкой, вопрос там, где он настоящий, ссылка — в реплае, никаких промокодов и скидок, страна выпуска карты не называется (инвариант из CLAUDE.md переносится и сюда).

### Шаблон A — короткий одиночный пост (150–300 знаков)

```
[Факт-хук: что вышло, одной фразой]
[Что это меняет для обычного человека — 1–2 фразы своими словами]
[Настоящий вопрос читателю ИЛИ сухая точка]
```

Пример (тема: вышла новая модель ИИ):

```
Вышла Claude Opus 5. Для обычного человека новость одна: она перестала терять нить в длинном разговоре — можно кинуть ей договор на 40 страниц и спорить о пунктах час.
Всё остальное в релизе — бенчмарки для разработчиков.
Кто уже потрогал: разницу видно или это снова маркетинг?
```
(≈ 290 знаков, 0 эмодзи, без ссылки; topic tag через параметр: `нейросети`)

### Шаблон B — пост + 2–3 реплая-продолжения

```
Пост 1 (хук + главный вывод, ≤ 300):
[Событие] [Для кого это важно и почему — одной мыслью]

Реплай 1 (что конкретно изменилось, ≤ 400):
[2–4 строки «было — стало» тире или цифрами]

Реплай 2 (сколько стоит / как получить, ≤ 400):
[Цена, лимиты бесплатной версии, где включить — факты без оценок]

Реплай 3 (ссылка, ≤ 200):
[Одна фраза, зачем идти по ссылке] [ссылка]
```

Пример:

```
Пост 1:
GPT-6 вышла и наконец объяснила, зачем обычному человеку платная подписка: она теперь помнит тебя между чатами. Не «контекст 1 млн токенов», а буквально — что ты просил на прошлой неделе.
Три вещи, которые реально изменились — ниже.

Реплай 1:
— Память: сама сохраняет твои предпочтения, можно посмотреть и стереть
— Голос: перебивать можно, как живого человека
— Файлы: до 50 документов в одном чате, раньше — 10
Бенчмарки пропускаю, они тебе ни о чём.

Реплай 2:
Цена не изменилась: бесплатно — с лимитом сообщений, Plus — $20 в месяц, доступ в тот же день. Память включается в настройках, по умолчанию выключена.

Реплай 3:
Если нужна подписка, а карта не проходит — вот как это решается за пару минут: [ссылка на бота]
```

### Шаблон C — пост-вопрос (обсуждение)

```
[Наблюдение или честное сомнение в одну-две фразы]
[Конкретный вопрос, на который ты сам хочешь знать ответ]
```

Пример:

```
Каждая новая модель обещает «думать лучше», а я по-прежнему прошу её переписать письмо начальнику и найти рецепт.
Честно: что вы делаете с нейросетью такого, чего не делали год назад?
```
(≈ 210 знаков; автор обязан отвечать в комментариях первые 2 часа)

### Правила линта и промпта

**Жёсткие (линт роняет пост):**

1. Длина каждого поста и реплая ≤ **480** знаков, где эмодзи считается за 4, URL — полной длиной (запас под расхождение «байты vs знаки»).
2. Никакой разметки: запрещены `*`, `_`, `#` в начале строки как markdown, HTML, символы из блоков Unicode «Mathematical Alphanumeric Symbols», таблицы (`|`), буллеты `•`/`▪️`/`◾`.
3. Нет заголовка: первая строка — законченное предложение ≤ 120 знаков, не капс целиком (капс — только у одного слова, если очень нужно).
4. Ссылка: **ноль ссылок в первом посте**; в цепочке — не больше одной ссылки, только в последнем реплае; параметр `url` intent'а не используется.
5. Topic tag: ровно 0 или 1, через параметр `tag`, 1–50 символов, без `.` и `&`, без `#` в тексте.
6. Цепочка: 1 пост + ≤ 4 реплая; без нумерации «1/…», «часть 2».
7. Стоп-фразы engagement bait: «лайк если», «напиши да/+», «согласны?», «отметь друга», «розыгрыш», «кто со мной?» (и их вариации).
8. Стоп-фразы рекламы для РФ (72-ФЗ): «промокод», «скидка», «акция», «только сегодня/до …», «успей», «выгоднее всех», «лучший сервис»; допускается нейтральное «сервис оплачивает иностранные подписки за рубли».
9. Не называть страну выпуска карты; не показывать реквизиты и PAN на скриншотах (перенос инвариантов проекта).
10. Intent-URL: `encodeURIComponent` всего текста, переносы как `%0A`, домен `www.threads.com`, длина URL ≤ 4 000 символов (иначе — сократить текст).
11. Дисклеймер при упоминании Threads в **Telegram**-постах: «Threads*» + сноска про Meta; в самом Threads — не требуется.
12. Оригинальность: текст поста не совпадает с TG-постом ни одним предложением длиннее 8 слов (грубая проверка на копипасту).

**Мягкие (промпт, линт предупреждает):**

13. Целевая длина одиночного поста 150–300 знаков; реплая — до 400.
14. Эмодзи 0–3, не в начале строк.
15. Пост про новость заканчивается настоящим вопросом или сухой точкой — не «а вы как думаете?».
16. Одна идея на пост; списки ≤ 5 строк; каждая строка — одна мысль.
17. Тон: «ты», от первого лица, без канцелярита («данная модель», «является», «осуществляет») — прогонять через `humanizer-ru` в режиме audit.
18. К посту прилагается предложение картинки (скриншот/схема 4:5) и alt-текст ≤ 1 000 знаков с фактами.
19. Частота: 1–3 поста в день, не меньше 2–5 в неделю, не больше 5 в день; выходные не пропускать.
20. Процесс для человека: после публикации 15 минут на правку опечаток; первые 2 часа — отвечать на реплаи; раз в неделю смотреть Insights и Account Status.

## 9. Чего мы не знаем / противоречивые данные

1. **Эмодзи в лимите.** API считает байты UTF-8 (4 за эмодзи), инструменты практиков — 2 (UTF-16 code units). Как считает композер приложения — не задокументировано. Отсюда запас 480.
2. **Где именно лента режет пост** («… more»). Практики называют ~175 знаков «в зависимости от переносов»; первоисточник (threadstools.app) отдаёт 403, воспроизвести не удалось. Правило «хук ≤ 120 знаков первой строкой» — страховка, а не факт.
3. **Ссылка в посте vs в реплае.** Официальной позиции нет. Mosseri: не понижаем, но p(click) не ценим. Buffer 2026: посты со ссылками — худший формат по ER. Русскоязычный кейс: ×7 по просмотрам. Но выборка кейса — один автоматизированный аккаунт, а Buffer меряет реакции, не охват. «Ссылка в реплае» — консенсус практиков, не доказанный факт.
4. **Форматы.** Buffer 10.2025 (старая выборка): картинки > видео > ссылки > текст; Buffer 03.2026: видео > картинки > текст > ссылки. Официально: медиа **с текстом** лучше медиа без текста. Голый текст в среднем проигрывает, но русскоязычные практики (vc.ru, tengrinews) описывают текстовые залёты на 170 тыс. и 1,2 млн просмотров. Вывод: картинка помогает, но не заменяет хук.
5. **Лимиты постинга в приложении.** Meta не публикует. «20 в день», «1 в 2 часа для новых» — форумные слухи. Единственный воспроизводимый сигнал — падение охвата при 10–13 постах/день у одного RU-аккаунта.
6. **Влияние Snippet (10 000 знаков) на охват.** Данных нет. Одно наблюдение практика: «people don't really care for that feature». Через intent недоступен, так что для нас вопрос второстепенный.
7. **Unicode-«жирный».** Влияние на ранжирование неизвестно; известны проблемы доступности и поиска. Решение «не использовать» принято по доступности, не по данным о ранжировании.
8. **Российская аудитория.** Единственная цифра — 300,7 тыс. DAU от рекламного агентства (методика не раскрыта). Mediascope не публикует. Размер русскоязычной аудитории вне РФ известен только по рекламному кабинету Meta (DataReportal), который сам по себе оценочный.
9. **Языковой таргетинг рекомендаций.** Как алгоритм решает, кому показывать русскоязычный пост (по языку интерфейса? по интересам? с автопереводом?) — не документировано. Казахстанский сегмент «постоянно виден» русскоязычным из других стран — значит язык поста работает как сигнал, но это наблюдение.
10. **Баг `url` на Android.** Единственный источник — обсуждение в комьюнити разработчиков; статус на сентябрь 2026 неизвестен. Нужен живой тест.
11. **72-ФЗ и Threads.** Ни одного разъяснения ФАС или дела, где Threads назван по имени; применимость выводится из принадлежности Meta. Юридическая консультация обязательна до старта.
12. **Rate-limit ranking / «первые часы».** Никакого официального «окна». Все цифры («2 часа», «30–60 минут») — от практиков и вендоров.
13. **Вендорские исследования** (Teract 10 847 постов, RecurPost, Postory) — тексты продают свои инструменты; цифры вроде «×3,2» использую как направление, не как норму.
14. **«Не все комментарии хороши».** Фраза приписывается Mosseri в десятках гайдов 2026 года; дословного первоисточника не нашёл.
15. **Ноябрь 2024 → 2026.** Ребалансировка в пользу подписок (Nov 2024) официально не отменялась; при этом Mosseri в 2025 говорил об улучшении ранжирования ссылок, а Meta в 2026 добавила «Your Algo». Насколько сейчас доступны рекомендации новому аккаунту без подписчиков — только практика покажет. Вендор: «8–12 % reach rate для аккаунтов <10K» [СЛУХ].

## 10. Что проверить живым тестом перед запуском (чек-лист на 1 час)

1. Открыть intent-URL с кириллицей 480 знаков и `%0A` на iOS-Safari, Android-Chrome, десктопе — переносы и длина.
2. Тот же URL с `tag=нейросети` — тег подхватился, `#` в тексте не появился.
3. Опубликовать пост, ответить себе через «Add to thread» и через intent с `reply_post_shortcode` — что удобнее руками.
4. Ссылку в реплае — превью-карточка Telegram-бота выглядит прилично (og:image).
5. Проверить в настройках Account Status → «eligible to be recommended».
6. Через неделю сравнить в Insights просмотры постов со ссылкой в реплае и без ссылки вовсе.
