# Веб-сайт: дизайн и креативный план

**Версия:** 0.3 · **Дата:** 2026-06-09 · **Владелец:** @penkin · **Статус:** Фазы 0-5a реализованы (chat-first MVP на `/`, production build зелёный); правки по фидбеку владельца от 2026-06-09 внесены (см. §13)

Этот документ — дизайн-спецификация и план реализации публичного сайта. Он **дополняет** функциональную спеку [`web-chat.md`](web-chat.md): там — контракты, идентификация, anti-abuse, стриминг; здесь — визуальный язык, концепция и фазы. **При конфликте по поведению/контрактам побеждает `web-chat.md`**, по визуалу/тону — этот документ. Реализационные правила бренда и рецепты генерации ассетов вынесены в скилл [`.claude/skills/oplatishka-design`](../.claude/skills/oplatishka-design/SKILL.md).

## 1. Концепция: «Оплатишка — живой компаньон»

Сайт — это **не форма и не лендинг с чат-виджетом**, а разговор с персонажем. Большинство AI-чатов выглядят как стерильные серые боксы; наша дифференциация — залезть с ногами в характер маскота. Пользователь не «пишет боту», а **говорит с Оплатишкой** — дружелюбным гиком, который оплатит ему любую иностранную подписку.

Три столпа концепции:

1. **Персонаж как ведущий.** Маскот присутствует на экране и реагирует на ход диалога (idle → думает → радуется оплате). Он — лицо доверия в чувствительной теме (деньги, обход блокировок).
2. **Комикс/поп-арт как язык.** Жирные контуры, halftone-точки, «стикерная» обводка, реплики в виде комикс-облаков, жёсткие тени без размытия. Это прямо продолжает стиль уже готовых ассетов (лого + видео-маскот).
3. **Платёж как кульминация.** Подтверждение заказа — это панель комикса, а успешная оплата — штамп «ОПЛАЧЕНО» + конфетти + ликование маскота. Момент оплаты ощущается как награда, а не как форма.

### Тон голоса
Дружелюбный, лёгкий, на «ты» по согласованию с продуктовым тоном бота (берётся из системного промпта `@oplati/agent` — единый голос для TG и веба). Без канцелярита. Уверенный, но не развязный: речь идёт о деньгах.

## 3. Информационная архитектура (chat-first)

Одна основная страница `/` = полноэкранный диалог. Никаких лендинг-прелюдий.

```
/                         (chat-first homepage; SSR-каркас + клиентский чат)
  ├─ Шапка: «Оплатишка» + статус online + «Очистить диалог» + тумблер темы (без кнопки «Позвать оператора» — фидбек владельца; эскалация словами в чате → request_human)
  ├─ Лента диалога (комикс-облака, авто-скролл, tool-карточки; история восстанавливается из БД через GET /api/chat/history)
  ├─ Маскот-слот (ОДИН видимый маскот: правая панель на lg+, шапка на меньших экранах)
  └─ Поле ввода + отправка (quick-reply чипы убраны — фидбек владельца)
/chat                     (alias на / или редирект — для совместимости с web-chat.md)
/api/chat                 (POST {message} → {ok, text, toolCalls}; см. ADR §11)
/api/chat/history         (GET, read-only восстановление диалога по cookie-сессии)
/api/chat/clear           (POST, «Очистить диалог»: новый conversation, старый и сообщения остаются в БД)
```

**SEO-компромисс chat-first.** `/` остаётся SSR с осмысленными `<title>`/`<meta>`/OpenGraph и кратким текстовым описанием сервиса (визуально свёрнутым «О сервисе»), чтобы не потерять индексацию и красивые превью в мессенджерах. `web-chat.md` помечал `/chat` как `noindex`; так как чат теперь на `/`, индексируем `/` (лендинг-уровень), но не индексируем приватные состояния. Это расхождение с `web-chat.md` §SEO фиксируется здесь как осознанное (chat-first по запросу владельца) и должно быть отражено при обновлении `web-chat.md`.

**Shell (реализовано):** full-screen 3-панельный лейаут — слева навбар (`md+`): wordmark «Оплати подписки» + «Оплатишка» (чат, активно, иконка-облачко) + «Обучение» (курсы, mock, бейдж «Скоро»); центр — диалог (колонка `max-w-3xl`); справа (`lg+`) — панель с крупным реагирующим маскотом (свободно стоит, без рамки) + mock личного профиля («Гость», заказы/потрачено/Telegram — заглушки). Реплики бота — слева, пользователя — справа (teal); ширина облака ограничена для читабельности.

**Правило одного маскота (фидбек владельца 2026-06-09):** на экране в один момент виден **ровно один** Оплатишка. На `lg+` — крупный в правой панели; ниже `lg` — компактный в шапке. Аватары у реплик/в навбаре/в типинг-облаке — убраны. Ассет — PNG с прозрачным фоном («стикер», drop-shadow по силуэту), без рамок и тёмных плашек. «Живость» — микро-анимации по состоянию диалога: дышит (idle), качается (думает), подпрыгивает (оплата) + подпись «печатает…» в панели.

**Адаптив:** mobile-first, полная высота viewport (`100dvh`), безопасные зоны iOS. На мобиле навбар и панель профиля скрыты, чат — на всю ширину, маскот — реагирующий аватар в шапке.

## 4. Визуальный язык и токены

Палитра снята напрямую из ассетов (лого + кадры видео-маскота). Полные таблицы токенов — в скилле (`references/design-tokens.md`); здесь — суть.

### Цвет (бренд)
| Роль | HEX | Источник |
|---|---|---|
| Teal — primary | `#268B89` | худи (мид) |
| Teal — light | `#5B9C99` | худи (светлый) |
| Teal — deep | `#306874` | лого |
| Ink (контур/текст) | `#16151A` (≈`#0F0D11`/`#1D1A1D`) | контуры комикса |
| Paper / cream | `#FBFCF7` | заливка wordmark, стикер-обводка |
| Brown (акцент) | `#6E4E4C` | волосы |
| Skin | `#E7C1A9` | кожа |
| Glasses blue (акцент/ссылки) | `#2E3A8C` | синие очки |
| Noir bg (dark) | `#0F0D11` | фон видео/лого |
| Stamp red | `#C2362F` | штамп «ОПЛАЧЕНО» (классический) |

Семантика: dark-тема — фон `--noir`, поверхности `#1A1A20`, текст `--paper`, акцент `--teal-light`; light-тема (backlog) — фон `--paper`, текст `--ink`, акцент `--teal-deep`.

### Типографика
- **Display / бренд / штампы / кнопки:** рисованный «комиксовый» гротеск с кириллицей — **Balsamiq Sans** (400/700; максимум 700 — `font-extrabold` не использовать, синтетика размывает контур). История выбора: Baloo 2 отклонён (нет кириллицы) → Nunito (фаза 0-4) → Balsamiq Sans по фидбеку владельца 2026-06-09 («шрифт под общий вайб»).
- **Body / UI:** округлый дружелюбный гротеск с кириллицей — **Rubik** (заменил Manrope тем же фидбеком — слегка скруглённые углы поддерживают комикс-стиль, остаётся читабельным).
- Не использовать комикс-фонты без кириллицы (Bangers и т.п.) для русского текста — только латиница в звуковых эффектах, если понадобятся.

### Сигнатурные приёмы (то, что делает стиль «комиксом»)
- **Жёсткие тени без размытия:** `box-shadow: 4px 4px 0 var(--ink)` — стикерный/поп-арт объём.
- **Толстые контуры:** `border: 2.5px solid var(--ink)` на карточках/облаках/кнопках.
- **Halftone-оверлей:** полупрозрачный точечный паттерн (radial-gradient/SVG) на фоне и «заливках» — фирменная фактура.
- **Комикс-облака:** сообщения — speech bubbles с хвостиком (CSS `::after`-треугольник), у пользователя хвост справа, у Оплатишки — слева.
- **Скруглif:** карточки/панели 16–20px, облака — крупные асимметричные радиусы.
- **Пружинные easing'и:** появления «попают» (overshoot), не линейно затухают.
- **Комикс-скроллбар (`.comic-scroll`):** teal-«таблетка» с чернильным контуром вместо стандартной серой полоски — на ленте диалога и textarea. Webkit-псевдоклассы + `@supports`-фолбэк `scrollbar-color` для Firefox (Chrome 121+ игнорирует webkit-стили при заданном `scrollbar-color`).

### Доступность
Контраст AA на текстах поверх teal/halftone; halftone не снижает читабельность (паттерн только под крупными зонами, не под мелким текстом); `aria-label` на иконках; уважать `prefers-reduced-motion` (отключать idle-анимации маскота и конфетти).

## 6. Состояния маскота ↔ состояния диалога

Это ядро «живого компаньона». Каждое состояние — отдельный ассет (Higgsfield, image-to-image от исходного маскота для консистентности; см. скилл).

| Состояние диалога | Маскот | Ассет |
|---|---|---|
| Idle / приветствие | стоит, дышит, иногда подмигивает; машет на первый экран | базовое видео (есть) + «wave» |
| AI печатает (стрим) | смотрит вверх, «думает» (палец у подбородка) | поза «thinking» |
| Ответ получен | лёгкая улыбка, кивок | микро-реакция / базовый idle |
| Подобрал каталог | жест «вот варианты» (рука в сторону карточек) | поза «presenting» |
| Заказ подтверждён → оплата | прыжок/жест триумфа + конфетти | поза «celebrate» |
| Зову оператора | серьёзный, «передаю человеку» | поза «handoff» (опц.) |
| Ошибка/проблема | смущённое «упс» | поза «oops» (опц.) |
| Клик по маскоту (пасхалка, backlog) | подмигивает, бросает реплику | спрайты/короткий клип |

`prefers-reduced-motion` → показывать статичную позу без цикла.

## 7. Фичи: приоритизация

**v1 (в плане сейчас):**
1. **Живой маскот-реакции** — главный носитель характера. Усилие: среднее (нужны 4–6 ассетов + state-машина состояний). WOW: высокий.
2. **Комикс-карточки (каталог → заказ → штамп «ОПЛАЧЕНО»)** — превращает сухие tool-результаты в визуальную кульминацию. Усилие: среднее-высокое. WOW: высокий. Главный «продающий» момент.
3. **Quick-reply чипы** — убирают страх чистого листа, поднимают конверсию первого сообщения. Усилие: низкое. ROI: высокий. **Делать первым** как дешёвую победу.

**Backlog (vibe-слой, после v1):**
- Лента соцдоказательства («кто-то оплатил Midjourney») — только на реальных анонимных данных, аккуратно с приватностью.
- Тонкие поп-звуки на сообщения (off по умолчанию).
- Тумблер light «бумажный комикс» / dark «комикс-нуар».
- Пасхалки по клику на маскота.

## 8. Технический стек фронта

Согласуется с `tech-stack.md` и `web-chat.md`:
- **Next.js 16 App Router** (уже есть), RSC-каркас `/`, клиентский чат-островок.
- **Vercel AI SDK v6** — `useChat` против `POST /api/chat` (SSE). Сервер: `streamText` + тот же системный промпт и tools из `@oplati/agent` (через `ToolHandlers` в `apps/web/lib/tool-handlers/` — уже реализованы).
- **Tailwind v4** (уже есть) — токены через `@theme` в `globals.css`; CSS-переменные бренда.
- **Анимация:** `framer-motion` (motion) — состояния маскота, флип карточек, slam-штамп, конфетти (`canvas-confetti` или собственный).
- **Компоненты:** при желании `shadcn/ui` как база примитивов (кнопки/инпут), но визуально перекрытая комикс-токенами; не обязательна для v1.
- **Рендер AI-текста:** лёгкое форматирование (RichText): абзацы, списки `- `/`1.`, `**bold**`, автолинк `https://...`. НЕ полный markdown (без заголовков/таблиц/HTML) — ADR-расширение `web-chat.md` «plain text» по фидбеку владельца (нечитаемые простыни). Богатый контент — только через tool-карточки.
- **Без новых клиентских секретов:** все вызовы AI/БД — через server route (`web-chat.md` §Что запрещено).

Границы пакетов не нарушаются: UI живёт в `apps/web`, агент — в `@oplati/agent`, БД — за `ToolHandlers`.

## 9. Ассеты для генерации (Higgsfield)

Генерируем через скилл `oplatishka-design` (рецепты) поверх `higgsfield-generate` / `higgsfield-product-photoshoot`. Консистентность лица/стиля — **image-to-image от исходного маскота** (`--image <файл/upload_id>`).

Список v1:
- Маскот-позы: `thinking`, `presenting`, `celebrate`, `wave` (+ опц. `handoff`, `oops`).
- Прозрачный PNG маскота (для слота без чёрного фона) — вырезка/перегенерация.
- Halftone-текстуры/паттерны фона (tileable), teal-вариант.
- Рамка/подложка карточки сервиса в комикс-стиле (опц. — можно чистым CSS).
- Favicon/OG-картинка на базе лого.
- (backlog) короткие idle-клипы под доп.состояния.

Исходники бренда: `content_site/` (лого 2 шт + видео-маскот 5 сек). Не коммитить «сырьё» в публичные ассеты без оптимизации.

## 10. Фазы реализации

> Код по фазам — отдельными тикетами (`/aif-plan`), здесь — карта. DoD каждой фазы — `pnpm typecheck && pnpm lint` зелёные + ручной smoke на preview-боте/URL.
>
> **Статус реализации (2026-06-09):** Фазы 0-4 — DONE (typecheck/lint/`next build` зелёные; верифицировано рендером и валидацией endpoint'ов). Полный e2e платёжного «оплачено» проверяется только с живой платёжной инфрой. Фаза 5 — backlog.

- **Фаза 0 — фундамент дизайна (без бэкенда).** Дизайн-токены в `globals.css` (`@theme`), шрифты (Baloo 2 + Manrope), базовые комикс-примитивы (облако, кнопка, карточка, жёсткая тень, halftone-оверлей). Статичная демо-страница компонентов. *Можно начать сразу — не блокируется агентом.*
- **Фаза 1 — `/api/chat` + минимальный поток.** Endpoint на AI SDK v6 (`streamText` + tools из `@oplati/agent`), cookie-сессия, rate-limit (см. `web-chat.md`). UI: лента облаков + ввод + typing. Quick-reply чипы (дешёвая победа).
- **Фаза 2 — маскот оживает.** Генерация поз (Higgsfield), state-машина «состояние диалога → поза», `prefers-reduced-motion`. Idle-видео в слоте.
- **Фаза 3 — комикс-карточки.** Рендер `search_catalog` → колода, `propose_order` → панель заказа + «Подтвердить», `confirm_order` → блок оплаты.
- **Фаза 4 — кульминация оплаты.** Штамп «ОПЛАЧЕНО» (slam), конфетти, ликование маскота; live-обновление статуса оплаты (webhook → realtime/poll).
- **Фаза 5 — полировка / vibe-слой (backlog).** light/dark-тумблер, звук, лента соцдоказательства, пасхалки, OG/SEO-доводка, a11y-аудит.

## 11. Открытые вопросы / риски

- **Кириллица в комикс-фонтах.** РЕШЕНО на Фазе 0: Baloo 2 кириллицу НЕ покрывает → display-шрифт = **Nunito** (800/900, есть кириллица), body = **Manrope** (есть кириллица). Подтверждено рендером `/styleguide`.
- **Производительность маскота на мобиле.** Видео-луп + halftone могут грузить слабые устройства — иметь статичный fallback и lazy-load; уважать `prefers-reduced-motion`.
- **Соцдоказательство и приватность.** Лента — только обезличенные данные, без сумм/имён; иначе не делать.
- **Расхождение с `web-chat.md` по SEO/маршруту `/chat`.** Зафиксировано в §3; при следующем редактировании `web-chat.md` синхронизировать (или оформить ADR).
- **ADR (Фаза 1): стриминг отложен.** `web-chat.md` §Стриминг предписывал Vercel AI SDK `streamText`/`useChat`. Но реальный агент `@oplati/agent` устроен на `@anthropic-ai/sdk` и НЕ стримит (возвращает финальный текст + `toolCalls`); AI SDK не установлен. PRD-инвариант «оба канала используют ОДНОГО агента» приоритетнее детали стриминга → `/api/chat` переиспользует `runAgent`, клиент шлёт `{ message }`, история — из БД. Token-стриминг вернётся, когда/если агент отрефакторят на стрим. Контракт: client POST `{ message }` → `{ ok, text, toolCalls }`.
- **Стоимость генерации ассетов.** Higgsfield — платный; генерировать пакетно, переиспользовать, держать исходники в `content_site/`.
